# Переусложнение мультиагентных схем генерации кода

Автор: Дурынин Павел Валерьевич, НИТУ «МИСиС».

Тема: зависимость эффективности мультиагентной генерации кода от сложности задачи и силы базовой модели.

Статья включает введение, обзор работ, постановку задачи, описание методов и список литературы. Описан протокол будущего исследования; эксперименты и заключение пока не включены.

## Статья и PDF

- [Текст статьи в LaTeX](article.tex).
- [Сборки GitHub Actions](https://github.com/NewaccOOO/multiagent-code-generation/actions/workflows/build.yml). В последней успешной сборке PDF доступен в разделе Artifacts как `article.pdf`.

PDF автоматически собирается при каждом push и pull request. Используется исходный класс оформления преподавателя: две колонки, Times New Roman, сборка Tectonic на Windows.

## Локальная сборка

При установленном Tectonic:

```bash
make article
```

Результат: `build/article.pdf`. Для Overleaf можно выполнить `make dist`, загрузить архив `dist/misis-article.zip` и выбрать XeLaTeX.

Форк [шаблона преподавателя](https://github.com/sadekovlar/misis-article-latex). Класс оформления распространяется по LPPL 1.3c; лицензия сохранена в [LICENSE](LICENSE). Каталог `example/` содержит исходный пример шаблона.
